# B8A1

## Assignment: Problem Solving with TypeScript & OOP

This assignment covers core TypeScript concepts: optional parameters, union types and type narrowing, readonly tuples, generics, interfaces, access modifiers, inheritance and Promises.

## Problem Solving

All 8 solutions are in [`solutions.ts`](solutions.ts):

1. `multiplyValue`: optional parameter with a default of 2
2. `processInput`: union types and `typeof` narrowing
3. `formatCoordinate`: readonly tuple
4. `concatenateArrays`: generics with rest parameters
5. `Course` and `getPopularCourses`: interface and filtering
6. `pluckValues`: generics with `keyof`
7. `Employee` and `Manager`: classes, inheritance and access modifiers
8. `validateAgeAsync`: Promises with `setTimeout`
